# Introduction

This introduction explains the Tooling course and how it is made. The domain represents 14% of the Certified GitOps Associate (CGOA) examination and belongs to ATP013. It has three pages: a welcome page that says who the course is for and how it is laid out, a page that lists the tools to install on your machine, and a page that describes how the course is written and checked. The course then starts with manifest format and packaging, which covers Helm charts and Kustomize overlays.
