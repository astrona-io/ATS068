# Welcome To The Course

This course is for learners preparing for the Certified GitOps Associate (CGOA) examination. It covers Tooling, worth 14% of the published curriculum. The examination tests knowledge through multiple-choice questions. The explanations build the reasoning needed to choose an answer, and the hands-on labs let you see each tool work on a real cluster.

At the end, you can explain and compare the four competencies of the domain: manifest format and packaging (Helm and Kustomize), state store systems (Git and alternatives such as OCI registries and buckets), reconciliation engines (Argo CD, Flux and alternatives), and interoperability with notification, observability and continuous integration tools. You can also run Argo CD and Flux against a Git repository and read what they report. Technical terms and acronyms are defined when they appear. Examples use a small set of example workloads named `scout`, `shuttle` and `probe`. The names identify workloads only and do not change the technical meaning.

Each section begins with an introduction and learning outcomes. Each module starts with a short map, continues with teaching parts, and ends with a summary. Every module has a playground, which is a clean Kubernetes cluster you can explore without any task, and a graded lab, which gives you a task and checks the result on the live cluster. Each section ends with a capstone lab and a knowledge check. A final knowledge check closes the course.

Read the examples carefully, identify which component does the work, and predict what changes when a condition changes. The practice questions are original and are not copied from the examination.
